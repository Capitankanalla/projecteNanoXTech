# 🚀 Estudi & Desenvolupament Web | Full-Stack Solutions

---

## 📌 Sobre el Projecte

Aquest repositori conté la plataforma web principal i l'ecosistema d'eines de la nostra agència. El projecte combina un lloc web corporatiu orientat a la conversió i la captació de clients amb un portal de gestió centralitzat per a projectes web i aplicacions.

L'objectiu central és oferir una experiència digital fluida, ràpida i segura, servint alhora com a **demostració tècnica i aparador d'enginyeria web**.

---

## 🎯 Serveis & Solucions

* **Disseny & Desenvolupament Web a Mida:** Llocs web d'alt rendiment, optimitzats per a SEO i adaptats a qualsevol dispositiu.
* **Desenvolupament de Web Apps:** Aplicacions dinàmiques, panells de control (dashboards) i plataformes SaaS.
* **Integració d'APIs & Serveis:** Desenvolupament d'APIs RESTful i connexió amb serveis de tercers.
* **Manteniment & Escalabilitat:** Arquitectures netes, segures i preparades per al creixement.

---

## 🔒 Seguretat i Autenticació

El sistema d'autenticació està dissenyat amb una arquitectura híbrida i robusta:
* **Auth0:** Gestió d'usuaris, Social Logins i fluxos d'autenticació delegats per al Portal de Clients.
* **JWT (JSON Web Tokens):** Autorització basada en rols i protecció d'endpoints privats a la REST API de Node/Express.
