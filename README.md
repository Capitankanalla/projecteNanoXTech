# 📘 README — Web Corporativa & Portfoli (Agència / Estudi Web)



## 🧭 Objectiu del projecte
Crear una web moderna, ràpida i altament orientada a la conversió per oferir serveis de disseny web, desenvolupament Full Stack i aplicacions web a mida. 

La web ha de servir com a eina de vendes directa per tancar els **primers 5-6 clients clau** i garantir la viabilitat financera dels pròxims 6 mesos, transmetent:
* **Capacitat tècnica real:** Demostració directa de domini Full Stack (rendiment, arquitectura, seguretat).
* **Orientació a negoci:** No només fer "webs boniques", sinó solucions que generin valor i resultats.
* **Confiança i proximitat:** Tracte directe amb l'desenvolupador/dissenyador sense intermediaris.
* **Claredat i transparència:** Processos de treball ben definits i serveis comprensibles.

## 🏗️ Estructura i Fases del Projecte

El projecte s'executarà de manera incremental per tenir una versió operativa com més aviat millor (MVP de conversió) i anar afegint funcionalitats segons les necessitats de negoci.

### Fase 1 — MVP Estàtic & Captació (Frontend Pur)
* **Header:** Logo, navegació clara i botó d'acció directament a contacte/reunió.
* **Hero Section:** Titular d'impacte basat en valor ("Transformo la teva idea o negoci en una aplicació web d'alt rendiment"), subtítol explicatiu i CTA principal.
* **Secció de Serveis:**
  * Disseny & Desenvolupament Web a mida (HTML/CSS/JS).
  * Web Apps & Integracions complexes (Node.js/Express/APIs).
  * Optimització, SEO Tècnic i Manteniment.
* **Secció "Com treballo" / Procés:** Explicació en 3-4 passos de la metodologia de treball (Presupost -> Disseny -> Desenvolupament -> Entrega).
* **Secció de Prova Social / Portfoli:** Treballs anteriors, cas de concepte o projectes personals destacats.
* **Formulari de Contacte (Visual):** Captació ràpida de lead (Nom, Email, Tipus de projecte, Pressupost estimat).
* **Footer:** Dades de contacte directes (email, telèfon, WhatsApp), xarxes/GitHub i avisos legals.
* **Disseny Responsivitat Total:** Adaptació perfecta a mòbil, tauleta i escriptori.

### Fase 2 — Identitat Visual, UX & Optimització
* Definició final de la paleta de colors i sistema de disseny.
* Implementació de tipografies i jerarquia visual clara.
* Animacions subtils (micro-interaccions en hover, scroll, botons) per millorar la percepció de qualitat.
* Optimització d'imatges, assets i rendiment (Core Web Vitals al 100%).

### Fase 3 — Backend, Captació Activa & Autenticació Bàsica
* **API pròpia (Node.js + Express):**
  * Endpoint per processar formularis de contacte.
  * Sistema d'enviament de correus automàtics (Nodemailer / Resend).
  * Validació de dades al servidor i protecció contra spam (reCAPTCHA / Turnstile).
* **Autenticació & Seguretat (JWT / Auth0):**
  * Configuració de seguretat base en l'API (Middleware de validació de tokens).
  * Endpoint d'administració privat (ús intern) per rebre o gestionar les sol·licituds de contacte directament.

### Fase 4 — Integracions & Escala (Futur)
* Multiidioma (CAT / ES / EN).
* Integració de calendari per a reserves de reunions (Calendly / Cal.com).
* Desplegament i CI/CD integrat (GitHub Actions + Render / Railway / Vercel).
* *(Futur segons creixement)*: Portal o àrea privada per a clients.

## 🎨 Disseny i Identitat Visual

### Paleta de Colors Recomanada
* **Fons / Base fosca (opcional mode fosc):** `#0F172A` (Slate profund — modernitat i tecnologia)
* **Accent principal:** `#2563EB` (Blau corporatiu — confiança, enginyeria)
* **Accent secundari / Energia:** `#10B981` (Verd esmeralda — conversió, creixement, èxit)
* **Text principal:** `#1E293B` / `#F8FAFC`
* **Grisos neutres:** `#64748B` (Subtítols i vora de targetes)

### Tipografia Recomanada
* **Primària (Cos i interfície):** Inter o Plus Jakarta Sans
* **Secundària (Titulars):** Poppins o Space Grotesk (to més tecno/modern)

### Principis de Disseny
* **Directe al gra:** Poques paraules, missatge clar i sense tecnicismes innecessaris per al client final.
* **Alt rendiment:** Carregament instantani (Sense carrgues pesades inútils).
* **CRIs (Crides a l'acció):** Visibles a cada secció per facilitar que el client contacti en qualsevol moment.
